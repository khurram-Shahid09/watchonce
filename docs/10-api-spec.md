# 10 · API Spec (v1)

Base URL: `/api/v1`. JSON everywhere. Auth: `Authorization: Bearer <jwt>` (dashboard) or `Bearer <pat_…>` (extension / API). The full OpenAPI document is generated by FastAPI at `/api/v1/openapi.json`. The dashboard client is generated from it.

Conventions: cursor pagination (`?cursor=&limit=`), errors as `{ "error": { "code": "workflow_not_found", "message": "...", "details": {} } }`, idempotency key header `Idempotency-Key` on POSTs that start work.

## Auth & workspace
| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | email, password, name, org_name → tokens |
| POST | `/auth/login` | → access (15 min) + refresh (30 d, httpOnly cookie) |
| POST | `/auth/refresh` | rotate refresh token |
| POST | `/auth/logout` | revoke refresh |
| GET | `/auth/google/start`, `/auth/google/callback` | OAuth |
| GET | `/me` | user + memberships |
| GET/POST/DELETE | `/tokens` | personal access tokens for the extension |
| GET/POST/PATCH | `/orgs/{org_id}/members` | invite / change role (owner only) |

## Recordings
| Method | Path | Description |
|---|---|---|
| POST | `/recordings` | `{description, start_url, event_count, frame_count}` → `{id, upload: {events_url, frames: [{name, url}]}}` presigned PUTs (15 min) |
| POST | `/recordings/{id}/complete` | verifies objects exist → enqueues compile → `202` |
| GET | `/recordings/{id}` | status, error, resulting workflow_id |
| GET | `/recordings` | list |

## Workflows
| Method | Path | Description |
|---|---|---|
| GET | `/workflows` | list with active version, last run status, success rate |
| GET | `/workflows/{id}` | details + versions summary |
| PATCH | `/workflows/{id}` | name, description, manual_duration_sec, settings |
| DELETE | `/workflows/{id}` | archive |
| GET | `/workflows/{id}/versions/{v}` | full spec + SOP |
| POST | `/workflows/{id}/versions` | save edited spec → new version (validated; `422` with validator errors) |
| POST | `/workflows/{id}/versions/{v}/activate` | make active (owner) |
| GET | `/workflows/{id}/versions/{v}/sop.pdf` | SOP PDF |
| GET | `/workflows/{id}/versions/{v}/export/playwright` | `.py` file |
| PUT | `/workflows/{id}/secrets/{secret_name}` | bind an org secret |

## Secrets

| POST | `/secrets` | `{name, values: {username, password}}`, encrypted on receipt |
| PUT | `/secrets/{id}` | rotate |
| DELETE | `/secrets/{id}` | |

## Runs
| Method | Path | Description |
|---|---|---|
| POST | `/workflows/{id}/runs` | `{inputs, version?}` → `{run_id}` (`202`) |
| POST | `/workflows/{id}/batches` | multipart CSV + `{column_map, approve_all?}` → `{batch_id}` |
| GET | `/batches/{id}` | progress + counts |
| GET | `/batches/{id}/results.csv` | results |
| GET | `/runs` | filter by workflow, status, date |
| GET | `/runs/{id}` | run + steps + outputs + artifact URLs (presigned GET) |
| POST | `/runs/{id}/cancel` | |
| POST | `/runs/{id}/checkpoints/{step_id}` | `{decision: "approve" \| "reject", note?}` |

## Heals
| Method | Path | Description |
|---|---|---|
| GET | `/heals?workflow_id=&decision=pending` | list |
| GET | `/heals/{id}` | before/after images, explanation |
| POST | `/heals/{id}/decision` | `{decision: "approve" \| "reject"}` → activates or archives the pending version |

## Analytics & audit
| Method | Path | Description |
|---|---|---|
| GET | `/analytics/summary?range=7d` | runs, success rate, hours saved, heal count, LLM spend |
| GET | `/audit?cursor=` | owner only |

## WebSockets
| Path | Messages (server → client) |
|---|---|
| `/ws/runs/{id}?token=` | `frame {jpeg_b64, step_id}` · `step {step_id, status, rung}` · `checkpoint {step_id, screenshot_url, reason, heal?}` · `heal {step_id, explanation}` · `done {status, outputs}` |
| `/ws/org?token=` | `recording.compiled`, `run.finished`, `heal.pending` notifications |

## Rate limits (MVP)
- 60 req/min per token for general endpoints
- 10 compiles/hour and 200 runs/hour per org (configurable per plan)
