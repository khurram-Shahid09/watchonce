# 10 · API Spec (v1)

Base URL: `/api/v1`. JSON everywhere. Auth: `Authorization: Bearer <jwt>` (dashboard) or `Bearer <pat_…>` (extension / API). The full OpenAPI document is generated by drf-spectacular at `/api/v1/schema/` (Swagger UI at `/api/v1/docs/`). The dashboard client is generated from it.

**Workspace context:** tenant endpoints act in one organization. A PAT is bound to its org. With a JWT, send `X-Org-Id: org_…` to pick a workspace (default: the caller's oldest membership). A workspace the caller doesn't belong to returns `404`, so ids can't be probed. Owner-only actions return `403 owner_required`.

Conventions: cursor pagination (`?cursor=&limit=`), errors as `{ "error": { "code": "workflow_not_found", "message": "...", "details": {} } }`, idempotency key header `Idempotency-Key` on POSTs that start work.

## Auth & workspace
| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | email, password, name, org_name → tokens |
| POST | `/auth/login` | → access (15 min) + refresh (30 d, httpOnly cookie `wo_refresh`, path `/api/v1/auth/`). Throttled per IP (20/min) and per account (5/min). |
| POST | `/auth/refresh` | rotate refresh token. Replaying an already-rotated token revokes all of the user's sessions (reuse detection). |
| POST | `/auth/logout` | revoke refresh, clear cookie |
| GET | `/auth/google/start`, `/auth/google/callback` | OAuth |
| GET | `/me` | user + memberships; with a PAT also `token: {id, name, org, expires_at}` (the extension shows the workspace from it) |
| GET/POST | `/tokens` | personal access tokens for the extension. `POST {name, expires_in_days?}` returns `token` (`pat_…`) once. Needs a dashboard session (a PAT can't mint PATs). |
| DELETE | `/tokens/{id}` | revoke |
| GET/POST | `/orgs/{org_id}/members` | list (members) / add an existing account by email (owner) |
| GET/PATCH/DELETE | `/orgs/{org_id}/members/{member_id}` | change role / remove (owner). The last owner can't be demoted or removed (`409 last_owner`). |

## Recordings
| Method | Path | Description |
|---|---|---|
| POST | `/recordings` | `{description, start_url, event_count, duration_ms?, frames: ["frames/0001.webp", …]}` → recording + `upload: {events_url, frames: [{name, url}], expires_at}` presigned PUTs (15 min). Send `Content-Type: application/json` for events and `image/webp` for frames. |
| POST | `/recordings/{id}/complete` | verifies every file exists and is within size limits (`409 upload_incomplete` with `details.missing`, `413 file_too_large`) → enqueues compile → `202`. Idempotent. |
| POST | `/recordings/{id}/compile` | compile again after a failure (`409 not_failed` otherwise) → `202` |
| GET | `/recordings/{id}/candidates` | normalized candidate steps with locators (output of the deterministic compile stages); `409 candidates_not_ready` before that |
| GET | `/recordings/{id}` | status, `error` + `error_code` (e.g. `budget_exceeded`, `compile_invalid`, `llm_refusal`), resulting `workflow_id` |
| GET | `/recordings` | list |

## Workflows
| Method | Path | Description |
|---|---|---|
| GET | `/workflows` | list with active version, last run status, success rate |
| GET | `/workflows/{id}` | details + versions summary |
| PATCH | `/workflows/{id}` | name, description, manual_duration_sec, settings |
| DELETE | `/workflows/{id}` | archive |
| GET | `/workflows/{id}/versions/{v}` | full spec + SOP |
| GET | `/workflows/{id}/versions` | version list, newest first |
| POST | `/workflows/{id}/versions` | `{spec, change_note?, base_version?, activate?}` → new version (validated; `422 invalid_spec` with `details.errors[{path, message}]`). Saved as `draft` unless `activate` (owners only). Removing an approval checkpoint is audit-logged (`workflow.checkpoint.removed`). |
| POST | `/workflows/{id}/versions/{v}/sop` | rewrite the SOP with the AI (synchronous; `503 llm_unavailable` leaves it unchanged) |
| GET | `/workflows/{id}/screenshots/frames/{n}.webp` | `302` to a short-lived link to a recording screenshot |
| POST | `/workflows/{id}/versions/{v}/activate` | make active (owner) |
| GET | `/workflows/{id}/versions/{v}/sop.pdf` | SOP PDF |
| GET | `/workflows/{id}/versions/{v}/export/playwright` | `.py` file |
| PUT | `/workflows/{id}/secrets/{secret_name}` | bind an org secret |

## WebSockets
| Path | Messages (server → client) |
|---|---|
| `/ws/runs/{id}?token=` | `frame {jpeg_b64, step_id}` · `step {step_id, status, rung}` · `checkpoint {step_id, screenshot_url, reason, heal?}` · `heal {step_id, explanation}` · `done {status, outputs}` |
| `/ws/org?token=` | `recording.compiled`, `run.finished`, `heal.pending` notifications |

## Rate limits (MVP)
- 60 req/min per token for general endpoints
- 10 compiles/hour and 200 runs/hour per org (configurable per plan)
