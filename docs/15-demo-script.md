# 15 · Demo Script (2 minutes)

Audience: engineering managers, ops leaders and recruiters in the Canada network. They watch on a phone, possibly muted, so **use captions on every scene**.

| Time | Scene | On screen | Caption / voice-over |
|---|---|---|---|
| 0:00–0:10 | **Hook** | Split screen: someone typing invoice #37 of 50 into a clunky portal | "Sara enters 50 invoices into this vendor portal every day. It takes her 3 hours." |
| 0:10–0:30 | **Watch once** | Click extension → Record → do the task once (~15 s, sped up 2×) → Stop → type "Create a vendor invoice" | "She shows WatchOnce how to do it. **Once.**" |
| 0:30–0:50 | **AI understands** | Dashboard: SOP appears with screenshots. Inputs auto-detected: `vendor_name`, `amount`, `due_date`. "Submit" marked 🔒 Approval required. | "AI turns the recording into a documented procedure and a reusable automation. It figured out the inputs, and that Submit needs a human." |
| 0:50–1:10 | **Run at scale** | Upload `invoices.csv` (50 rows) → live view shows the bot filling the form fast. Approval card → Approve all. Progress 50/50 ✅ | "Upload a spreadsheet. The bot does all 50, and asks before submitting anything." |
| 1:10–1:35 | **The magic: self-healing** | Toggle "Portal v2" (buttons renamed and moved). Run again → step 6 turns amber: "Button 'New invoice' not found → healed to 'Create invoice' (confidence 0.94)". Before/after screenshots. Run completes. | "Next month IT updates the portal. Normal bots break here. **WatchOnce repairs itself**, shows exactly what changed, and waits for approval." |
| 1:35–1:50 | **Enterprise-ready** | Quick cuts: audit log, encrypted credentials, domain allowlist setting, "AI cost per run: $0.00" | "Deterministic runs, zero AI cost per run, a full audit trail, and credentials never exposed." |
| 1:50–2:00 | **Close** | Analytics: "42 hours saved this month". Logo + your name + link | "3 hours a day back for Sara. Built by Khurram Shahid. Link below." |

## Recording tips
- 1920×1080, browser zoom 110%, hide bookmarks bar, clean demo data
- Record each scene separately and cut together (Loom, OBS or Screen Studio)
- Keep a static "architecture diagram" frame ready for longer (5-min) technical versions
